# 状況グラフの内訳に「おおよその時間」を出す 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 状況グラフの棒（1日）を押して出る内訳で、各区域の名前の横に、その日に回ったおおよその時間（例 `17〜18時台`）を出す。

**Architecture:** 数えるのは `joukyou-graph.js` の `build({ terr: true })`（棒を押したときだけ動く道）だけに足し、ふだんのグラフの計算は変えない。家・日ごとの「最初と最後の記録の時刻」を区域×欄（area/card/unsplit）ごとに最小・最大でまとめ、`detail()` の行に持たせる。画面は `rowHtml` で区域名の横に1つの span を足すだけ。

**Tech Stack:** 素の JavaScript（ビルドなし）、試験は auto リポジトリの node 試験（`tests/site`）と Playwright の画面試験（`tests/e2e`）。

**Spec:** `docs/superpowers/specs/2026-11-21-jg-jikan-design.md`

## Global Constraints
- 出すのは **日の内訳だけ**（`unit === 'day'`）。週・月の内訳では出さない
- 家・部屋が **10軒未満**の区域は出さない（カルテと同じ `SL_AZA_MIN`・`karteHomes`）
- 形：`{最初の時}〜{最後の時}時台`、同じ時なら `{時}時台`。時は端末の時刻の 0〜23
- 時刻は記録の `v.at`。数えない拒否（`skipRefused` が理由を返すもの）は時刻にも入れない
- 区域カード・留守宅カード・分けられない記録の欄は、それぞれの欄に入った家（その日の分類）の記録だけで時間を出す
- サーバー（gas）・データの形・数（訪ねた・会えた・留守・拒否）・並び順・ほかの画面は変えない
- ふだんのグラフ（`terr` なし）の結果と速さは変えない
- 版は `2026.13.174`（index.html の app-version・app.js の APP_JS_VER・sw.js の `kuiki-app-v174` の3か所）。お知らせは区域係だけ（`role: 'admin'`）
- 作業ブランチ：kuiki-map・auto とも `feat/jg-jikan-20261121`。main へのマージ・公開は本人の承認のあと

## Review Focus
1. 日時として読めない `at` の記録 → 今までどおり数えず、時間にも入れない（行が出ても時間が壊れない）→ Task 1 J-6
2. 数えない拒否しかない区域・時刻の家 → その記録の時刻は範囲に入らない → Task 1 J-4
3. 「次の日 ›」「‹ 前の日」で移ったとき、時間もその日のものになる（前の日の時間が残らない）→ Task 2 E-3
4. 360px・とても大きい文字で、長い区域名＋時間が横にはみ出さない → Task 2 E-5
5. 同じ区域が区域カードと留守宅カードの両方の欄に出る日 → 欄ごとに別の時間 → Task 1 J-3

### Task 1: 数える（区域×欄ごとの最初と最後の時刻）

**Files:**
- Modify: `kuiki-map/joukyou-graph.js`（`build` の `processList`・`bump`・戻り値、`detail`、`api`）
- Test: `auto/tests/site/joukyou-graph.test.js`（末尾の `report` の前に J-1〜J-7 を足す）

**Interfaces:**
- Produces:
  - `build(o)` の戻り値に `terrSpan: Map<日付文字, Map<区域id, Float64Array(6)>>` を足す。並びは `[area最小ms, area最大ms, card最小, card最大, unsplit最小, unsplit最大]`、記録のない欄は `Infinity, -Infinity`。`o.terr` がないときは空の Map
  - `detail(r, p)` の各行に `span: { area: [lo, hi] | null, card: … , unsplit: … }`（ms。その期間の最小・最大）
  - `hourSpan(lo: number, hi: number) -> string`：`'17〜18時台'`／`'17時台'`／どちらかが有限でなければ `''`。時は `new Date(ms).getHours()`。`api` に足して出す

- [ ] **Step 1: 試験を書く**（`L(y,m,d,h,mi)`・`V`・`run`・`SKIP` は既存の道具を使う）
  - J-1：TA の家1軒、10/24 の 17:10 留守・18:40 会えた → `JG.detail(run(vs,{terr:true}), {from:'2026-10-24',to:'2026-10-24'})` の TA 行の `span.area` が `[17:10 の ms, 18:40 の ms]`、`JG.hourSpan(...)==='17〜18時台'`
  - J-2：2軒を 17:05・17:50 → `'17時台'`
  - J-3：同じ区域で、家 h5 を `src:'card'` で 10:00、家 h1 を `src:'area'` で 17:00 → `span.card` は 10時台、`span.area` は 17時台（欄ごとに別）
  - J-4：17:00 会えた（u1）と 20:00 拒否（u3、`skipRefused: SKIP({u3:'adm'})`）→ `span.area` は `'17時台'`（20時は入らない）
  - J-5：10/24 と 10/25 に記録 → `detail` を 10/24 だけで呼ぶと 10/25 の時刻は入らない。`terr` なしの `run` では `r.terrSpan.size===0`、`r.days` は `terr:true` のときと同じ（JSON で比べる）
  - J-6：`at:'こわれた'` の記録と 9:30 の記録 → `'9時台'`（こわれた記録は入らない）
  - J-7：`JG.hourSpan(Infinity,-Infinity)===''`、`JG.hourSpan(NaN,5)===''`、23:30 と翌日 0:10 は別の日になる（10/24 の行は `'23時台'`）

- [ ] **Step 3: 作る**

  - `bump` の `withTerr` の中だけで、その欄の最小に `Date.parse(first.at)`、最大に `Date.parse(newest.at)` を入れる（`withTerr` でないときは Date.parse を呼ばない）
