# 区域をもらう・留守宅カードをえらぶ：はじめ5件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 区域をもらう・留守宅カードをえらぶを、表示に関係なくはじめ5件＋「もっと見る」にする。
**Architecture:** schedule.js の openRequestSheet / openAwayPick の件数の決まりだけを変える。版とお知らせは最後に main に乗せ直してから。
**Tech Stack:** 素の JS（GitHub Pages）、試験は Playwright（tools/*.mjs、試作モード）。
**Spec:** docs/superpowers/specs/2026-11-17-hyouji-5ken-design.md

## Global Constraints
- 5件（REQ_FIRST = 5）。留守宅カードの上限 20件はそのまま
- 文言は今の「もっと見る（あと{0}件）」を使う（スペイン語の訳はある）
- 新しいボタン・設定・画面は足さない。既存の機能を1つも無くさない

## Review Focus
- 受け取れる区域が3件・係に頼む区域が10件 → 受け取れる3＋係に頼む2、見出しは両方出る
- ちょうど5件 → 「もっと見る」を出さない
- もっと見るのあと並べ方を変える／地図で見てもどる／地域のようすからもどる → 開いたまま
- 区域カード⇔留守宅カードの切りかえ・ホームから開き直し → 5件にもどる
- 390px・1280px、日本語・スペイン語で横にはみ出さない・JS エラーなし
