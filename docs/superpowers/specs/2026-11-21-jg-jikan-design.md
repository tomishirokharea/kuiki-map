# 状況グラフの内訳：区域ごとに「おおよその時間」を出す（短い設計・2026-11-21）

## ねらい
状況タブのグラフで棒（1日）を押すと出る内訳で、区域ごとに「だいたい何時ごろ回ったか」を出す。
会えた割合と並べて見ることで、どの時間帯がよく会えるかを一目で分かるようにする（R A さんの依頼）。

## やること
- 内訳の各区域の行で、区域名の横に時間を足すだけ（例：`区域33-2　17〜18時台`）
  - 時間は、その区域・その日に数えた記録の時刻を「時台」で出す。記録のある時が続いている所を1まとまりにし、**記録のない時間が1時間以上あいたら分けて出す**（例：`9〜10時台・17〜18時台`。2026-11-21 追加：午前と夕方に分けて回った区域が「9〜20時台」のように広く出ないように）
  - 1時間の中のまとまりは `17時台` とだけ出す
  - 訪ねた・会えたなどの数は、時間で分けず今までどおり1行（R A さんが「時間だけ分ける」を選んだ）
  - 区域カードの欄と留守宅カードの欄は、それぞれの欄に入った家の記録だけで出す（同じ区域が両方の欄に出たら、別々の時間）
  - 数えない拒否（自動・区域係・係がえらんだ人）は、今までどおり数えないので、時刻にも入れない

## やらないこと
- 時間帯ごとの会えた割合の表は足さない（案C は見送り。いちばん簡単な形にする）
- 週・月の内訳では出さない（何日分も混ざって幅が広がり、かえって分かりにくいため）
- サーバー（gas）・データの形は変えない。数（訪ねた・会えた・留守・拒否）・並び順・ほかの画面は変えない

## きまり・注意
- 家・部屋が10軒未満の区域は時間を出さない（カルテの時間帯の表 `SL_AZA_MIN` と同じきまり。数え方もカルテの `karteHomes` と同じ）
- 時刻は「記録ボタンを押した時刻」（`v.at`）。あとでまとめて入力した人の分は、実際に回った時刻とずれる
- 日は端末の時刻（今のグラフと同じ）

## 考えた案
- 案A：時刻の幅だけを区域の行に足す → **採用**（のちに、記録のない時間が1時間以上あいたら分ける形に直した。時間ごとに数も分ける形は見送り）（場所は「区域名の横か数字の行の、見やすいほう」と任された。数字の行はスマホですでに2行に折り返しているため、区域名の横にする＝Claude の判断）
- 案B：区域の行を時間帯（朝〜夜）ごとに分けて会えた割合を出す → 行が長くなり「データ少」だらけになるので見送り
- 案C：案A＋上に時間帯ごとの会えた割合の表 → 依頼は「足すだけでいい」なので見送り

## 作る人にまかせること
- 数えるのは棒を押したときの `build({ terr: true })` の中だけ（ふだんのグラフの速さは変えない）
- 見た目（文字の大きさ・色）は今の行の `small` に近い控えめなものに。読み上げでも時間が読めること
- スペイン語の表示（i18n-es-joukyou.js）に訳を足す
