## 要件
| ID | 内容 |
|---|---|
| R1 | 再訪問の地図（`followMap`）の一軒家の印：拒否 →「拒」（今までどおり）／一度でも会えた記録 →「会」／記録はあるが会えていない →「留」／記録なし → 白い丸。記録はだれのものでも数える（一覧と同じ `sum(k)`）。オレンジの輪・タップ・地図の範囲は変えない |
| R2 | 再訪問の地図以外の印は、R1 では変わらない |
| R3 | `periodStart`：今の決め方（続き・途中返却・受け取り・返却・完了）で日付がないときだけ、紙の日付を使う。紙で貸し出し中（`paperLentAt`）が紙で回り終えた日（`paperDone`）と同じ日か後なら、貸した日の0時（回り終えたその日に次の人へ貸すことがあるため・監査 Important 1）。そうでなければ回り終えた日の翌日の0時（どちらも端末の時刻）。今より先の日付（入力ミス）・読めない日付・ない日は使わない。ISO の日時は端末の時刻の日付として読む。どれもなければ空のまま。区域ごとに結果を覚えておく（地図を動かすたびに呼ばれるため） |
| R4 | R3 は `periodStart` を使う所すべてにそろって効く（地図の印・小さな点・集合住宅の部屋の色と残りの数・二世帯住宅・記録を直す画面の説明）。おすすめ・進み具合・留守宅カード・S-13・印刷は変えない |
| R5 | 全件の処理を足さない |
| R6 | 版 2026.13.177。変更の一覧に載せる（news の印は付けない） |

- 区域の日付そのものの直し、消えた家の再訪問の整理、一覧の「留守のまま」の札（記録のない再訪問にも出る）の見直し
