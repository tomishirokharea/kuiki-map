## 6. 作り（どう実装するか）

### 6.1 数の持ち方（`joukyou-graph.js`）
- `tally()` を `{ met, refused, away, rMet, rAway }` にする（`refused` は**残す**。数える拒否があるため）。`rMet`・`rAway` は**おすすめ経由の内数**（会えた・留守のうち）。
- 1日・1カテゴリあたりの数は 5つ。`counts` の 1日分は 3カテゴリ×5＝**15**（今は 3×3＝9）。
- 外した拒否の数は、カテゴリに分けず**日ごとに理由別の3つ**（自動・不明／区域係／えらんだ人）だけ持つ（グラフの下の1行に使う）。
- `rate(t, minN)` は今のまま（`n = met + refused + away`、`pct = met / n`）。
- おすすめのききめ用に `recoRate(t)` を足す：おすすめ経由（訪ねた `rMet + rAway`／会えた `rMet`）と、おすすめ以外（訪ねた `n - rMet - rAway`／会えた `met - rMet`）の2組と、使用率（`(rMet + rAway) / n`）。

### 6.2 数えない拒否を外す（R1・R2c）
- `build` の入力に `o.skipRefused(v)` を足す（真なら数えない）。画面の `inputs()` が次の判定を渡す：
  - `v.auto` などの自動の印がある、`v.by` が空、`v.by` が名簿（`D().people`）にいない → `'auto'`
  - その人の `role === 'admin'` → `'adm'`
  - 係の端末の「数えない人」に入っている → `'pick'`
  - どれでもなければ `''`（数える）
- `processList` の中で、`v.result === 'refused'` かつ判定が空でないときだけ**読み飛ばす**（`continue`）。これで同じ日の丸め・`first`（その日の最初の訪問）・カードの印の判定からも外れる。外した数は理由別に日ごとに足す。
- 人の判定は、`by` ごとに `Map` で1回だけ引く（30万件でも名簿を何度も引かない）。
- 外した拒否だけの日・家は、棒にも内訳にも出なくなる（訪ねた軒数0）。

### 6.2b 「拒否を数えない人」（R2b）
- 保存：`localStorage` の `kuiki_jg_noref_<使う人のid>`（JSON の配列）。この端末だけ。
- えらぶ画面：グラフの下の小さな文字のボタン → 既存の `setSheet`（下から出る画面）。名簿の人を、拒否の記録の件数が多い順に並べ、`件数 0軒` の人は「ほかの人をすべて見る」を押したときだけ出す（一覧が長くならないように）。
- 区域係は行を出すが、チェックは付いたまま押せない（「自動で除外」）。
- 「閉じる」で保存して描き直す（`st.agg = null` で数え直す）。

### 6.3 おすすめ経由の振り分け（R3・R4）
- `kindOf(v, key, day)` を次の順に変える：
  1. `src` の先頭が `reco` **かつ その訪問が今の巡回の中**（`Date.parse(v.at) >= 巡回の始まり`。R12c）→ **履歴で判定**（下の `recoKind`）。カードの印は見ない。
  2. `src` の最後の語が `card`／`area`（`:p` を除く）→ 今のまま。
  3. 印なし → 今のまま（90日以内は推定、それより前は `unsplit`）。
- `recoKind(v, list, i, terrId)`：
  - 区域の巡回の始まり `lentAt = Date.parse(o.roundStart(terrId))`。`o.roundStart` は新しい入力で、画面（`inputs()`）では既存の式をそのまま使う：`t.holder ? (roundFromOf(t) || t.lentAt) : (t.lastRoundFrom && t.lastRoundFrom < t.lastLentAt ? t.lastRoundFrom : t.lastLentAt)`。区域ごとに `Map` で覚える。試験では差し替え可能な関数として渡す。
  - 家の記録リスト（新しい順）の `i+1` 以降（＝その訪問より古い記録）を順に見て、**拒否を除いた最初の記録**を探す。
    - その記録の時刻が `lentAt` 以上（＝今の巡回の中）なら、結果が `away` → `card`、`met` → `area`。
    - その記録が `lentAt` より前（＝前の巡回）なら → `area`（この巡回では初めて訪ねた＝回り残し）。
    - 記録がなければ → `area`。
  - `lentAt` が読めない・その訪問より後なら、巡回の判定をやめ、拒否を除いた直前の記録が `away` → `card`、それ以外 → `area`（R4）。
  - **おすすめ自身の見分けとそろえる**：「今の巡回でまだ訪ねていない家」は、前の巡回に留守の記録があっても**回り残し（区域カード側）**に数える。これは `leftOf`（`app.js:9893`）の見分けと同じで、`umItem`（留守宅）との重なりをこの順で解く。
  - 巡回の始まりは `roundBounds(tid)` の `ext ? ext.start : start`（完了して誰も持っていない区域は、終わった巡回から続けて見る。`umItem`・`leftOf` と同じ扱い）。
- 走査は**おすすめ経由の記録のときだけ**行う（1件につき、拒否を飛ばしながら最大数件）。区域の `lastLentAt` は家の区域ごとに `Map` で覚える。
- 期間の外の記録も履歴として読む必要があるため、`processList` の打ち切り（`fl === 2` で `break`）より**後ろの要素も参照できる**ことを前提にする（リストはもともと家ごとの全記録なので、参照は可能。打ち切りは「数えるのをやめる」だけ）。

### 6.4 おすすめ経由の内数（R6）
- `bump(id, terr, first, res)` に、`first` の `src` が `reco` で始まるかの真偽を渡し、`rMet`／`rAway` を増やす。
- **決め（私の判断）**：おすすめ経由かどうかは**その日・その家の最初の訪問**で決める。おすすめで行って留守、同じ日にもう一度行って会えた場合も「おすすめがきっかけ」として数える。カードの印と同じ基準にそろえ、1日1軒の数え方を崩さないため。

### 6.5 棒（R7〜R9）
