# S-13の記録を直す（ポップ）／未来日を止める　設計　2026-11-20

承認：R A さん（2026-11-20）。A・B を実施、C は今回触らない。

## 1. なぜ

区域61-7の紙の記録に、完了日 **2026/12/31**（未来）が入っていた。10/31 の入力ミスと見られる。
R A さんが直そうとしたが直せなかった、という報告から調べた。

### 分かったこと（実際に動かして確かめた）
- **「直す」は壊れていない。** 試験用の写し（架空データ・Playwright）で再現したところ、`[data-s13ed]` を押すと
  見出しが「紙の記録を転記する」→「紙の記録を直す」に変わり、名前・割り当て日・完了日がすべて欄に入り、
  ボタンも「この内容に直す」になり、「直すのをやめる」も出る（6/6 合格）。
- **直せなく見える理由は見え方。** 押すとパネル全体が描き直されて**先頭に戻る**。
  欄が埋まるのは1画面半ほど下で、変わるのは見出しの2文字だけ。スマホでは何も起きていないように見える。
- **未来日を止めるものが、どこにもない。**
  - 入力時：`openS13Edit` の確かめは `c < a`（完了日＜割り当て日）だけ
  - 帯の集計：`obiCover_`（gas/hagemashi.gs）は `S <= c < Z` の上限だけ見る。未来の完了日も「回り終えた」に数える
  - 自動の確かめ：`lowSweep` は `now - Date.parse(r.at) < wait` で待つので、`r.at` が未来だと**永久に対象外**

## 2. 目的・しないこと

**目的**
- 係が、S-13の紙の記録の中身をスマホで迷わず直せる
- 未来の完了日が、入ることも・数えられることも・確かめをすり抜けることもない

**しないこと（非目標）**
- アプリの記録（`returns`）の日付を書き換えられるようにすること。今回は紙の記録だけ
- 留守宅の段階が確かめられない件（紙運用からの移行の穴）。C として見送り
- 帯の文（S5）の言い回しの変更
- 枝番の重みの偏り（分母が枝番ごと）の見直し

**失敗とみなすこと（アンチゴール）**
- 1件の入力ミスを直したつもりで、枝番すべてが書き換わる
- 既存の「転記する」欄や、アプリの記録の扱いが変わる
- 未来日を弾いたせいで、正しい完了が数から落ちたまま誰も気づかない

## 3. approaches（検討した作り方）

| 案 | 中身 | トレードオフ |
|---|---|---|
| ① 今の欄まで自動で動かす | 「直す」で欄までスクロールし、色を付ける | 一番小さい。だが長いパネルの中なので、どこを編集中か分かりにくいまま |

| ③ 表のマスを直接編集 | S-13の表のセルをその場で書き換え | 誤タップでデータが変わる危険。確認を挟みにくい |

## 4. 作るもの

### A. 紙の記録を直すポップ
- S-13 → 区域の行 → 「この年度の割り当て」の紙の記録の「直す」を押すと、**その記録だけのポップ**が前に出る
- 中身：伝道者の名前／割り当てた日付／完了した日付（まだなら空）／「保存する」／「やめる」
- 「保存する」→ 上書きの確認。**変更の前後を見せる**（例：`2026/10/8 〜 2026/12/31` → `2026/10/8 〜 2026/10/31`）→「上書きする」で確定
- **枝番への一括反映はしない**（直すときはその区域だけ）。新しく入れるときの「枝番すべてに入れる」は今までどおり
- 長いパネルの下の「紙の記録を転記する」欄は、**新しく入れる用として今までどおり**残す
- 今ある `openS13Edit(tid, editId)` の編集モード（欄が埋まる形）は、ポップに置きかえる

### B. 未来日を止める（3段）
1. **入力時**（ポップと、転記の欄の両方）：完了日・割り当て日が今日より後なら保存しない。
   文：「完了した日付が、今日より後になっています」／「割り当てた日付が、今日より後になっています」
   ※ 割り当て日の未来チェックは、グループに渡す経路には既にある（`a > ymd(new Date())`）。紙の記録の経路に無い
2. **帯の集計**（`gas/hagemashi.gs` の `obiCover_`）：完了日が今日より後のものは数えない。
   `returns`（`r.at`）・`s13`（`p.c`）の両方
3. **自動の確かめ**（`app.js` の `lowSweep`）：`r.at` が未来でも確かめの対象から外れないようにする

## 5. 守ること（制約）

- 既存の機能を無くさない。転記の欄・枝番一括・前回完了日・アプリの記録の「完了にする」「消す」はそのまま
- 新しいタブ・新しい画面は作らない。ポップは既存の確認ダイアログ（`ask`）と同じ見た目・操作に合わせる
- スペイン語（`i18n-es-*.js`）の辞書を足す
- 幅375px・390px で横のはみ出し0px
- `s13` の記録の形（`{id, kind, terrId, name, a, c}`）は変えない。サーバーの列も変えない
- 本番反映の順：サーバー（auto）が先 → 画面（kuiki-map）
- 版番号・`sw.js` の更新を忘れない
